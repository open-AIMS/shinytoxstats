# shinytoxstats: A Graphical Interface to the toxstats Toxicity Endpoint Methods

A Shiny application providing a point-and-click interface to the
'toxstats' package, which computes the standard endpoints of a
concentration-response toxicity test by the decision rules the US EPA
Whole Effluent Toxicity method manuals set out. Data are entered by
pasting, by uploading a comma-separated file, or by uploading a
spreadsheet laid out to the supplied template. Results are presented as
the decision trail that justifies the selected test, alongside the
endpoints and a concentration-response plot, and can be exported as a
report, a spreadsheet, or the R code that reproduces the analysis.
